# План розробки Simple Weather App (Brighton & Open-Meteo)

Цей план складено відповідно до технічного посібника `Technical Tutorial Step-by-Step Guide.md`. Мета проекту — створення навчального погодного додатку на чистому HTML та JavaScript без використання сторонніх бібліотек.

---

## Загальні вимоги та правила
- **Стек:** Тільки чистий HTML та Vanilla JavaScript (код безпосередньо в тегу `<script>` або у відповідних файлах на етапі рефакторингу).
- **Зрозумілість:** Простий і читабельний код для початківців із докладними коментарями над кожною функцією.
- **Джерело даних:** Open-Meteo API (без потреби в API-ключах чи реєстрації).
- **Копірайт:** Обов'язкова наявність напису `"Weather data by Open-Meteo.com"`.
- **Автономність:** Робота без серверної частини (відкриття файлу подвійним кліком у браузері).

---

## Етап 1: Налаштування та конфігурація API (Stage 1)
**Мета:** Створити базову структуру сторінки, зберегти конфігурацію міста та сформувати URL для запиту.

- [x] **1.1. Базова розмітка HTML:**
  - Створити документ з заголовком, контейнером для назви міста та посиланням на сформований API URL.
  - Додати підпис-копірайт *"Weather data by Open-Meteo.com"*.
- [x] **1.2. Конфігураційний об'єкт `CONFIG`:**
  - Оголосити об'єкт `CONFIG` із полями:
    - `town`: `"Brighton"`
    - `latitude`: `50.8284`
    - `longitude`: `-0.1395`
  - Додати коментар із поясненням, що Open-Meteo не потребує API-ключа, але саме тут він зберігався б у разі потреби.
- [x] **1.3. Функція `buildUrl()`:**
  - Реалізувати функцію, яка за допомогою конкатенації рядків (`+`) створює повну URL-адресу для запиту прогнозу:
    - Параметри: `latitude`, `longitude`, `current=temperature_2m,weather_code,wind_speed_10m`, `timezone=Europe/London`.
- [x] **1.4. Відображення на сторінці:**
  - Вивести назву міста на сторінку.
  - Вставити сформований URL як гіперпосилання (`<a target="_blank">`), що відкривається в новій вкладці.
- [x] **1.5. Тестування:**
  - Відкрити сторінку, натиснути на посилання і перевірити коректність повернення JSON-відповіді в браузері.

## Етап 2: Отримання та відображення сирих даних (Stage 2)
**Мета:** Отримати дані за допомогою `fetch` (async/await) та вивести їх у вихідному форматі.

- [x] **2.1. Функція `loadWeather()`:**
  - Реалізувати асинхронну функцію з використанням `async/await`.
  - Виконати запит через `fetch(buildUrl())`.
  - Отримати відповідь та перетворити її на JSON (`response.json()`).
- [x] **2.2. Відображення JSON:**
  - Додати на сторінку тег `<pre id="raw-json"></pre>`.
  - Записати отримані дані у форматі тексту (`JSON.stringify(data, null, 2)`).
- [x] **2.3. Автозапуск:**
  - Викликати `loadWeather()` автоматично під час завантаження сторінки (`window.onload` або в кінці скрипта).
- [x] **2.4. Тестування:**
  - Перевірити відображення сирого JSON на сторінці.
  - Відкрити DevTools -> вкладка Network та переконатися у наявності успішного запиту (статус 200).

**Мета:** Виділити з JSON лише необхідні поля та обробити можливі помилки.

- [x] **3.2. Функція `showWeather(data)`:**
  - Передати отримані дані з `loadWeather` у функцію `showWeather`.
  - Заповнити відповідні `<span>` невідформатованими значеннями з `data.current`.
- [x] **3.3. Обробка помилок (`try...catch`):**
  - Огорнути виклик `fetch` і обробку даних у блок `try...catch`.
  - У разі помилки виводити користувачеві повідомлення: `"Could not load the weather."`.
- [x] **3.4. Тестування:**
  - Перевірити відображення значень на сторінці.
  - Протестувати поведінку при відсутності інтернет-з'єднання (повинно відображатися повідомлення про помилку).

## Етап 4: Форматування даних та кнопка оновлення (Stage 4)
**Мета:** Зробити дані зручними для читання та надати можливість ручного оновлення.

- [x] **4.1. Кнопка "Refresh data":**
  - Додати кнопку на сторінку, яка прив'язана до виклику `loadWeather()`.
- [x] **4.2. Функція форматування дати `formatDate(dateString)`:**
  - Реалізувати функцію, яка приймає рядок вигляду `YYYY-MM-DDTHH:MM` і за допомогою методу `split` формує `DD/MM/YYYY HH:MM`.
- [x] **4.3. Функція опису погоди `describeWeather(code)`:**
  - Перетворити код погоди WMO на текстовий опис:
    - `0` → Clear sky (Ясно)
    - `1-3` → Cloudy (Хмарно)
    - `45-48` → Fog (Туман)
    - `51-67` → Rain (Дощ)
    - `71-77` → Snow (Сніг)
    - `80-82` → Rain showers (Зливи)
    - `95+` → Thunderstorm (Гроза)
- [x] **4.4. Форматування температури:**
  - Додати символ `°C` до виведеного значення температури.
- [x] **4.5. Тестування:**
  - Перевірити читабельність дати та текстовий опис погоди.
  - Натиснути кнопку Refresh у DevTools Network і переконатися, що відправляється новий запит.
